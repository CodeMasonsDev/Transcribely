# Transcribely Docs Overview

Use this skill at the end of a feature or architecture change.

## Instructions

1. Summarize what changed.
2. Update documentation when needed.
3. Keep README content concise.
4. Put detailed architecture notes in `docs/agents/`.
5. Call out limitations and follow-up work plainly.

## Include

- feature summary
- affected files
- agent roles used
- quality checks run
- known limitations
- next recommended step

The final overview should be useful to a developer joining the project after the change.
